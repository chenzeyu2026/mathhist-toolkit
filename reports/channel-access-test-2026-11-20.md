## 二、逐渠道实测

### 1. z-Library 及镜像 —— 网络层阻断

【实测】
- 测试域名：`z-lib.io`、`zlibrary.to`、`1lib.sk`、`singlelogin.re`、`z-lib.gs`，`curl` 结果全部 `HTTP=000`。
- DNS 解析结果异常：`zlibrary.to → 157.240.12.50`、`z-library.sk → 31.13.81.4`（均为 Facebook 网段），`z-lib.io → 202.160.130.52`；属典型 DNS 污染/投毒特征。
- 详细握手：`z-lib.io:443` 与 `zlibrary.to:443` 均 **Connection timed out after ~20s**，未收到任何 HTTP 响应。
- 结论：**卡在网络层，未进入站点**，无法评估其检索与下载；本次不把任何「据称能下」当实测。

【公开】该站长期被多国执法查封、域名频繁轮换，且属侵权渠道。即使换网络可达，其文件版次/页码不可核，不能用于需要「某书某页如此说」的学术回填。

### 2. SaltyLeo（书签导航站）—— 书目/推荐层

【实测】
- `saltyleo.com` 301 到 `tstrs.me`，返回 200；站名「SaltyLeo 的书架 · 图书推荐及目录」。
- 站内公告：「站点索引突破 50 万本」；有「热门搜索」「书单」「大家都在看」「评分」。
- 站内搜索 `数学史` → **共 1244 条结果，耗时 16 ms**；结果字段为 书名 / 作者 / 出版社 / ISBN / 评分 / 简介。
- 详情页（如 `/b/中国数学史话`）外链域名仅 `tstrs.me`、`site-status.tstrs.me`、`afdian.com`（爱发电），**未见下载/在线阅读入口**。
- 命中的中文数学史多为通俗读物：数学史鉴、数学趣史、简明数学史（第二卷·中世纪数学）、中国数学史话等；**未确认 17 条英文专著**。

【判定】层级＝**目录/元数据**；门槛＝无（可直接检索，无需注册）；价值＝中文通俗书与版本线索，学术引用价值低。

### 3. SoBooks.cc —— 大众读物层

【实测】
- `sobooks.cc` 返回 200，标题「SoBooks – EPUB/MOBI/AZW3/PDF电子书免费下载」。
- **搜索被算术验证码拦截**：`?s=数学史` 返回「SoBooks 搜索验证：35 + 77 = ?」，需提交 `esc_captcha_result`。按纪律未绕过验证码。
- 分类只有：小说文学 / 历史传记 / 人文社科 / 励志成功 / 经济管理 / 学习教育 / 生活时尚 / 漫画绘本，**无数学/科学史分类**。
- 抽查「学习教育」40 本，标题几乎全是学习方法、写作、育儿、职场，数学相关仅《学习的逻辑》一本；「人文社科」「历史传记」抽查亦无数学史专著。
- 图书详情页（`/books/25661.html`）直接给出 **城通网盘 / 百度网盘 / 夸克网盘** 按钮，经 `go.html?url=<base64>` 跳转；页面未见登录墙。

【判定】层级＝**可触发网盘下载（PDF/EPUB/MOBI 不确定）**；门槛＝搜索算术验证码；网盘侧是否需登录/提取码未逐一验证（未下载任何文件）。价值＝**数学史学术书基本没有**，不适用。

### 4. 中国国家数字图书馆（文津搜索）—— 西文专著馆藏目录

【实测】
- `https://find.nlc.cn/` 的 HTTPS 握手失败（`HTTP=000`），**HTTP 可用**（`http://find.nlc.cn/` → 200）；主站 `www.nlc.cn` → 200。
- 检索接口 `http://find.nlc.cn/search/doSearch?query=...` 服务端渲染，可直接读结果。
- 17 条书目命中 **14 条**（详见第四节）；未命中 3 条：Enros 1983（期刊论文）、Plofker 2009、Kennedy 1980（后两者可能为检索词组合导致漏检）。
- 结果卡片含：文献类型、著者、出版年、出版社、来源数据库（如「馆藏外文资源」），并有 **摘要 / 目次 / 馆藏信息 / 在线阅读** 标签页。
- 关键门槛：页面提示「**未登录情况下不能使用在线阅读功能，请您先登录！**」。

【判定】层级＝**目录/元数据 + 摘要/目次 + 馆藏信息**，在线阅读/全文＝需登录（读者卡）；门槛＝注册读者卡（实名）；未注册，停在此页。

### 5. PubScholar 公益学术平台 —— 可进但检索受阻

【实测】
- `https://pubscholar.cn/` 返回 200；首页实时统计：**期刊论文 108,368,347、专利 106,756,088、科学数据 1,520,484、开源软件 4,083,277、图书专著 163,170**。
- 检索栏字段：主题 / 标题 / 关键词 / 作者 / 机构 / 出版物 / 摘要 / DOI；结果页路由为 `/explore`，含「论文 / 科学数据 / 科技语料 / 开源软件 / 科研设施 / 图书 / 专利」分栏与「可获取全文」筛选。
- 直接调用其后端 `https://pubscholar.cn/hky/open/resources/api/v1/articles` 返回：**「第三方应用独立请求时，无此操作权限」**（需页面内签名），因此**未能完成一次可复核的检索命中**。
- 结论：**访问到首页与检索界面，未完成查询**；不臆测命中数。

【公开】中科院文献情报中心主建、2023-11-01 发布，可检索元数据约 1.7 亿条，公益性、免费。

### 6. 国家哲学社会科学文献中心（ncpssd.org）—— 中文期刊/集刊免费全文

【实测】
- 默认 UA 访问返回 **403**；改用浏览器 UA 后 `https://www.ncpssd.org/` → 200（WAF 按 UA 过滤）。
- 检索「数学史」（服务端结果，浏览器实测）：**中文期刊文章 1357 篇、外文期刊文章 13 篇、集刊文章 3 篇**。
- 主要来源期刊：数学教育学报 98、数学教学通讯 70、**中国科技史杂志 41、自然科学史研究 40**、上海中学数学 37 等；高频作者：汪晓勤 37、代钦 11、岳增成 8、韩祥临 7、邹大海 6。
- 文献类型分栏含「外文图书」，说明有少量外文图书，但外文期刊仅 13 篇，**英文专著基本不覆盖**。
- 门槛：页面持续显示「登录 / 注册」入口；全文获取需注册登录（据公开资料为免费注册）。

【判定】层级＝**目录/元数据 + 摘要**（未登录）；全文需注册。价值＝**中文数学史/科学史期刊与集刊的第一免费来源**。

### 7. OpenSign 公益性学术资源服务平台 —— 英文 OA 补充

【实测】
- 域名 `https://opensign.lib.tsinghua.edu.cn/` → 200，站名「OpenSign公益性学术资源服务平台」。
- 主办：清华大学图书馆「开放科学支持计划」推进工作组运营；定位为整合全球 OA 资源、面向社会免费开放（据其 `/about` 页）。
- 免费、无需校园网；检索无需登录。
- 实测命中：
  - `history of mathematics` → **16 篇**（Article 18、Others 8、Book 2、Proceeding 1、Review 1；年份 1985–2025）
  - `history of the calculus` → **2 篇**
  - `Archive for History of Exact Sciences` → **0 篇**
  - `Analytical Society 1812` → **0 篇**
- 结果页出现 Blasjö、Hogendijk、Knobloch、Parshall 等数学史作者，说明确有小众数学史 OA 文献，但总量极薄。

【判定】层级＝**元数据 + OA 全文链接**；门槛＝无。价值＝**只补 2020 后英文 OA 论文**，不能当主力。

### 8. NSTL 国家科技图书文献中心 —— 外文原文传递

【实测】
- `https://www.nstl.gov.cn/` → 200（裸域 `nstl.gov.cn` → 000，需带 `www`）。
- 检索路径：首页「文献检索」→ 输入「数学史」→ 跳转 `search.html?t=JournalPaper,ProceedingsPaper,DegreePaper&q=<base64>`。
- **检索后立即弹出登录框**：「欢迎使用NSTL网络服务系统，请登陆 / 登录后可检索文献、查看详情与获取全文 / 登录」。**未登录看不到结果列表**，卡在登录页；未注册。
- 收费（`zgxa.nstl.gov.cn/help/zc_ff_sf.html` 实测）：
  - 普通文献：**复制费 0.30 元/页**；版权费 5–10 元/篇。
  - **个人用户和公益性机构用户不收版权费**；企业机构用户外文期刊/会议/文集 5 元/篇、外文学位论文/科技报告 10 元/篇。
  - 最终费用＝复制费＋（版权费）；西部用户可申请半价；不向大陆以外用户提供。
- 服务：注册用户「加入申请单」，服务馆 24 小时内提供原文传递，可选自助获取或电子邮件。
- 注册（`www.nstl.gov.cn/register.html`）：分个人用户 / 公益性机构用户 / 企业机构用户，**个人可直接注册下单**。

【判定】层级＝**原文传递（扫描件/电子件）**；门槛＝注册（个人可）；计费＝按页 0.30 元，个人免版权费。价值＝**补 NLC 拿不到的外文期刊论文与西文专著章节**（如 Enros 1983、AHES 论文）。

## 五、使用顺序与补缺口

1. **NLC 文津搜索（第一步，定书目）**
   - 作用：把 17 条（尤其西文专著）落到具体馆藏、出版社、年份，确认「这本书在哪、有没有」。
   - 缺口：在线阅读要读者卡；篇级外文期刊不覆盖。

2. **NSTL（第二步，拿外文原文）**
   - 作用：补 NLC 只给目录的那部分——外文期刊论文（Enros 1983、AHES）与西文专著章节，24 小时传递。
   - 成本：0.30 元/页，个人用户免版权费；需先免费注册个人用户。
   - 注意：未登录看不到结果，必须先注册再检索。

3. **ncpssd（中文侧免费全文）**
   - 作用：中文数学史/科学史期刊与集刊（中国科技史杂志、自然科学史研究），「数学史」1357 篇中文期刊。
   - 缺口：外文期刊仅 13 篇，英文专著不覆盖；全文需注册。

4. **PubScholar（中文专著 + OA 兜底）**
   - 作用：16.3 万图书专著的元数据、部分 OA 全文；本次未完成自动化检索，需人工在页内检索核实。
   - 缺口：无页面签名无法批量查；不要把首页统计当作数学史命中数。

5. **OpenSign（只补 2020 后英文 OA）**
   - 作用：免费、免校园网，能拿到少量近年英文 OA 数学史论文。
   - 缺口：覆盖极薄（history of mathematics 16 篇、AHES 0 篇），只能作补充。

6. **SaltyLeo（只找中文通俗书线索）**
   - 作用：确认某本中文数学史读物是否存在、出版社与 ISBN。
   - 缺口：无全文入口，学术引用价值低。

7. **SoBooks（不建议用于本任务）**
   - 作用：仅大众读物；学习教育分类 40 本无数学史；搜索有算术验证码。
   - 风险：网盘文件版次/页码不可核，不能用于回填。

8. **z-Library（不推荐）**
   - 本网络不可达；即便可达也属侵权渠道，文件不可作可引用页码来源，且有版权与合规风险。

**缺口补位对照**
- 17 条西文专著：NLC（定位）→ NSTL（传递）。
- Enros 1983 / AHES 等外文期刊论文：NSTL（主力）；OpenSign/PubScholar 仅 OA 兜底。
- 中文期刊论文：ncpssd（免费）。
- 中文专著：NLC + PubScholar。
- 2020 后英文论文：OpenSign / PubScholar 的 OA 优先，闭源转 NSTL。
