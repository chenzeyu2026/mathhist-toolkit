## 4. 方法与限制

### 4.1 实际用到的渠道

| 渠道 | 状态 | 用途 |
|---|---|---|
| OpenAlex API | 可用（免费，无 key，每日额度约 100 次请求） | 种子识别、被引/被引列表、被引数、书目、OA 标记 |
| Unpaywall API | 可用（免费，需 email 参数，无需 key） | 逐条 OA 判定、OA 类型、PDF 链接 |
| Semantic Scholar API | 429 限流，三次均失败 | 未采用 |
| zbMATH Open API | 未取到（查询超时） | 未采用 |
| archive.org | 本机网络不可达（与 11-18 记录一致） | 未能核验馆藏/借阅状态 |
| Gallica SRU | 403 | 未采用 |
| Google Books API | 超时 | 未采用 |

### 4.2 口径

- **被引数全部来自 OpenAlex API 返回的 `cited_by_count`**，没有一条是估的。专著在 OpenAlex 里被引普遍偏低（Boyer 只记 58 次），只能当下限看。
- **关系**只写实际查到的：`被引 X` 表示该条在 OpenAlex 的 `cites:<种子ID>` 结果里，即它引用了种子，不是种子引用了它。
- 种子著作的参考文献在 OpenAlex 里为 0 条记录（`referenced_works` 为空），所以「它引了谁」这一侧对四本专著没有产出，只能靠被引侧扩展。
- **书目以 OpenAlex 返回为准**；页码异常（如只有起始页）照录，不补齐。

### 4.3 与申请单的冲突点（需人工确认）

| 条目 | 问题 |
|---|---|
| Plofker 2009 | Unpaywall 的 OA 命中指向 Aestimatio 书评（DOI 10.2307/j.ctv1qgnq84.9 实际解析到书评），**不是正书**；正书仍需传递 |
| Robinson 1966 | OpenAlex 的 W1998146115 年份 1961、指向 Indagationes 论文；1966 年 North-Holland 版无独立记录，被引数不可用 |
| Belhoste / Katz / Needham / 郭书春 | OpenAlex 只有书评或教材条目，正书无记录，被引数「未取到」 |
| Enros 1983 | Unpaywall 判为 bronze（出版社页免费），是 17 条种子中唯一有 OA 记录的；若能打开，P0 里这一条不需要传递 |
