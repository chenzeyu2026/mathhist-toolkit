# 证据标记规范 v0.1

> 适用对象：数学史 / 数学思想演化类写作。
> 状态：v0.1 草案，条款可被质疑（见 §6）。
> 配套工具：`tools/mathlint`。规范里每条规则都注明「工具能否自动判定」，这是为了避免把工具做不到的事说成做到了。

---

## 0. 这份规范要解决什么

三个具体毛病：

1. **论断没有证据分级**：正文里"牛顿认为……""学界公认……"和"我读过原页"混在一起，读者无法判断哪句可核。
2. **一手文献散在多个库**：同一条文献在不同段落用了不同的写法，事后无法统一核查，也无法比对哪些段落用了不同等级。
3. **史实与流行误说混写**：科普叙事、教材边栏、百科条目与原始文献并列，误说被当作史实继承下来。

标记的作用不是"让文章显得严谨"，而是**让每一条可核查的断言都带着它的证据出处，从而可以被机器和人分别检查**。

---

## 1. 标记语法

```
〔<等级>｜<来源类型>:<出处>〕
```

- 括号：全角六角括号 `〔` `〕`（U+3014 / U+3015）。不用 `【】`、`[]`、`()`。
- 分隔符：等级与来源类型之间用全角竖线 `｜`（U+FF5C）。
- 来源类型与出处之间用冒号，**优先半角 `:`**；全角 `：` 也能被解析器接受，但同一文件内应统一。
- 等级只有一个字符，取值 `A` `S` `U` `F`。
- 出处不得为空。

### 1.1 四个等级

| 等级 | 名称 | 含义 | 可否单独支撑论断 |
|---|---|---|---|
| `A` | 原始文献 | 作者本人著作、手稿、书信、同时代期刊原始卷期、作者自序自注 | 可以 |
| `S` | 二手研究 | 同行评议专著与论文、学术版编者导言、权威辞书条目（如 DSB）、专家编纂全集的研究性附录 | 可以，但须与 A 对读 |
| `U` | 未核实 | 有线索（书目、馆藏、编号）但未见到原件/原页 | 不可以，必须留在台账里 |
| `F` | 流行说法 | 教科书、科普、百科、讲座、博客、视频、教材边栏 | 不可以，只能作线索 |

说明：本规范不用 `B`/`C`/`T` 三个字母。旧稿或外部指令集里的 B（权威二手）对应本规范的 `S`，C（流行转述）对应 `F`，T（转引）不是独立等级，而是 `S` 的一个必填字段（见 R5）。这样做的理由：等级只回答"证据离原件有多远"，转引回答"这条证据经过了谁"，是两个维度，压成一个字母会让"转引的二手研究"无处安放。

### 1.2 示例

```
〔A｜原始文献:Leibniz, "Nova methodus pro maximis et minimis", Acta Eruditorum, Oct. 1684, pp. 467–473〕
〔S｜二手研究:Grabiner 1981, pp. 45–52〕
〔U｜未核实:仅见 19 世纪书目著录，未见 1684 年原刊影像；待查 Acta Eruditorum 1684 年卷〕
〔F｜流行说法:某高数教材「历史注记」边栏：柯西消灭了无穷小〕
```

标记里的来源类型词由等级决定：中文写 `原始文献` / `二手研究` / `未核实` / `流行说法`。英文文档可沿用这四个中文标签，也可改用 `primary` / `secondary` / `unverified` / `popular`；解析器两套都接受，但要求标签与等级匹配。

### 1.3 多来源、嵌套、转引

- **一句多源**：并排写多个标记，中间不加逗号。`〔A｜...〕〔S｜...〕`
- **嵌套**：出处内部允许再出现一个标记，用于标明"这条二次文献转引了哪条原始文献"。解析器按括号深度配对，不做正则贪婪匹配。
  ```
  〔S｜二手研究:Boyer 1949, p. 212（其注引〔A｜原始文献:Newton, Principia, 1687, Lib. I, Lem. II〕）〕
  ```
- **转引**：只见到中转者、没见到被引文献原页时，出处必须同时写出中转者与最终文献，且等级不得为 `A`。
  ```
  〔S｜二手研究:转引自 Boyer 1949, p. 212；原文献 Cantor 1894, Bd. III, p. 89（未见原页）〕
  ```
  这里的"中转者"是**你实际翻到的那本书**（Boyer），不是被引者（Cantor）。

### 1.4 出处字段里机器可解析的四种标识

`mathlint` 会尝试解析下列标识，格式不合法报 `error`：

| 类型 | 写法 | 校验 |
|---|---|---|
| DOI | `DOI:10.1093/...` | 前缀 `10.` + 注册号 + `/` + 后缀；不含空格 |
| ISBN | `ISBN:978-0-387-...` | 10 位或 13 位，校验位必须正确 |
| URL | `https://...` | 必须有 scheme 与 host |
| 档案 ID | `ARK:ark:/12148/bpt6k205444w`、`E212`、`MS:<馆藏号>` | `ARK:` 后接 `ark:/` 前缀；Eneström 编号为 `E` + 数字 |

### 1.5 情境有效性：哪些字段不能同时出现

一个标记的出处不是自由填写的文本框，它由六个维度描述：

| 维度 | 取值 | 由哪条定义 |
|---|---|---|
| 载体 | 原刊/原文、同版式影印、重排重印、译本、点校本（未分层）、点校本正文、点校者校记、现代校勘转录、经作者校订的笔记、未授权学生笔记、作者晚年回忆、实名后人批注、佚名批注、二手研究转述、流行说法 | §1.1、R1–R4、R7、R9 |
| 定位完整度 | 版次+页码齐全 / 有版次无页码 / 待补 | R1(c)、R3 |
| 转引层数 | 0 / 1 / ≥2 | §1.3、R5 |
| 原文页码 | 有 / 无 | R2、R3 |
| 中转者 | 具名 / 佚名 / 无 | §1.3、R5 |
| 阻断原因 | 无 / 有线索未取原件 / 原件缺页 | R8 |

这六者**不总是互相独立**：**载体决定哪些维度有意义**。下面六条是硬约束，违反任一条不是"写法不规范"，而是这个情境不存在。

**E1 转引层数只在「经人转述」时有内容。**
只有载体是二手研究转述时，"转引了几层"才是一个事实。凡你自己持有载体（原刊、影印、译本、点校本、转录、笔记、批注、回忆），层数恒为 0。
- 判据：`载体 ≠ 二手研究转述 ⇒ 层数 = 0`。
- 含义：`〔A｜原始文献:Euler 1755, p. 12〕` 既不能同时声称"转引自某书"，也不能说"转引两层"。

**E2 中转者只在层数 ≥ 1 时存在。**
- 判据：`层数 = 0 ⇒ 中转者字段为空`；`出处含"转引自" ⇒ 层数 ≥ 1`。
- 含义：层数为 0 时写"中转者佚名"没有指称对象。

**E3 已持有载体时不得声称「未取原件」。**
"有线索但未取原件"与"载体是原刊/影印/点校本/转录"互否——既然填了这个载体，就是拿到了。
- 判据：`阻断原因 = 有线索未取原件 ⇒ 载体 = 二手研究转述`。其余载体上出现该阻断原因即无效。
- 写法含义：只想说"我知道有这份原件但没看"时，载体一栏应直接写 `U｜未核实`，而不是先写 `A` 再补一句"未见原页"。

**E4 缺页与「版次+页码齐全」互斥。**
"原件缺页/污损/无法释读"意味着那一页拿不到，定位不可能同时齐全。
- 判据：`阻断原因 = 原件缺页 ⇒ 定位完整度 ≠ 齐全`。
- 允许的组合是"有版次无页码"：知道在哪卷哪版，但那一页缺。

**E5 定位为「待补」时，阻断原因无指称。**
- 判据：`定位完整度 = 待补 ⇒ 阻断原因字段为空`；该情境一律判 `U`（见 R8）。

**E6 原文页码只在「所引载体指向另一份原文」时有内容。**
译本、二手研究转述、全集/点校本正文可以另给原文页码（R2、R3 的双定位）；载体本身就是原文（原刊）时，页码就是原文页码，该字段为空。
- 判据：`载体 = 原刊 ⇒ 原文页码字段为空`。
- 同版式影印通常也属这种情形，但为不与影印本自身新增的页码混淆，审计按独立字段计数，因此审计给出的情境数（v0.1 编码 168 / 90，v1 基线 160 / 86）都是**上界**。

**这六条怎么用。** E1、E3、E4 是**剔除类**：违反即情境不存在，共剔除 1244 个组合。E2、E5、E6 是**归并类**：违反不使情境消失，只是该维度无内容，同一情境的不同写法应合并计一次。15 类载体 × 3 定位 × 3 层数 × 2 原文页码 × 2 中转者 × 3 阻断 = 1620，经 E1/E3/E4 剔剩 376，再按 E2/E5/E6 归并，得 168（维度有指称即算活）与 90（只算被规则读取的维度）。v1 基线去掉未分层的第 5 类载体（见下段），空间为 1512 → 356 → 160 / 86；§5.1 报的是这一组。

载体一栏里的"点校本（未分层）"是一个已知歧义点：R2 说点校属编纂工作、整本当 `S`，R3 说点校本里的作者正文可作 `A`。两条并不矛盾——它们说的是同一本书的两层。但只有把"点校本"写成"点校本正文"或"点校者校记"，这个区分才落在文本里；不写清就仍是 15 类里的第 5 类，判定会摇摆。因此：**凡引点校本，必须指明是正文还是校记**；指明后载体即为 14 类。

压缩的理由不是让数字好看：被剔掉的组合描述的东西不存在，既不能支持论断也不能反驳论断，拿它们做分母只会得到虚高的冲突率。当前 `mathlint` 尚未实现 E1–E6 的检查，它只做括号配对与词表比对；实现时建议错误代码 `INVALID_CONTEXT`（剔除类）与 `DEGENERATE_FIELD`（归并类）。

## 2. 十三条判定规则

每条给：判定、正例、反例、工具可判定性（自动 / 部分 / 不可）。

### R1 什么算原始文献

**判定**：同时满足三条才是 `A`——(a) 文本由作者本人产生，或由同时代记录者在其授权下产生；(b) 文本与所述事件同时代（事件发生后不久、作者在世期间）；(c) 能定位到具体载体：版次/卷期/页码、手稿编号、信函日期与收件人。

常见边区：
- 期刊**原始卷期**（哪怕后来有重印）→ `A`。
- 作者本人撰写并授课的讲义 → `A`；**学生课堂笔记** → 待议（见 T-1）。
- 书信：作者亲笔或亲署 → `A`；后人编纂的书信集，正文 → `A`，编者注释 → `S`（见 R4）。

**正例**：`〔A｜原始文献:Leibniz, "Nova methodus pro maximis et minimis", Acta Eruditorum, Oct. 1684, pp. 467–473〕`
**反例**：`〔A｜原始文献:Boyer 1949, p. 212〕` —— Boyer 是 1949 年的研究著作，距 1684 年两百余年，不是同时代文本。
**反例**：`〔A｜原始文献:某百科「Acta Eruditorum」条目〕` —— 载体不是原始卷期。

**工具**：部分。工具只能按来源类型词表（如出现"维基/百科/教科书/textbook"却标 A）报不自洽，不能判断"是否同时代"。

### R2 译本算哪一级

**判定**：译本本身**不是**原始文献，单独引用译本 → `S`。若同时给出原文版次与原文页码，可以标 `A`，但出处必须**双定位**（原文页码 + 译本页码），否则视为不自洽。
古籍点校本的"点校"属编纂工作 → 点校者按编者处理（`S`）；**影印本**是按原件影印，文字可作 `A`，但不得用于纸张、水印、递藏等版本学判断（见 T-3）。

**正例**：`〔A｜原始文献:Newton, Principia, 1687, Lib. I, Lem. II（Motte 1729 英译本, p. 41）〕`
**反例**：`〔A｜原始文献:牛顿《自然哲学的数学原理》中译本, p. 41〕` —— 只有译本页码，无法回到原文。
**反例**：`〔A｜原始文献:Heath 英译《阿基米德全集》, p. 91〕` —— 英译本是 20 世纪译本，应标 `S`，除非同时给希腊原文校勘本页码。

**工具**：部分。出处里出现"译 / trans. / translation"却标 `A` 且只有一个页码定位时，报 `warn`。

### R3 再版与全集的关系

**判定**：初版、再版、重印是同一著作的不同**版本见证**。`A` 级要求"版次—页码"成对出现；跨版本混用页码是错的。
- 权威**全集**（如 Euler, *Opera omnia*）是编纂本：正文可作 `A`，但若同时知道原刊卷期页码，优先给原刊，全集页码作补充。
- 现代**重印本**（Dover、Cambridge 重印）不构成新证据，不得因为"我没见过 1687 年版，只见 1999 年重印"就改变版次信息；后者只是获取入口（见 R11）。

**正例**：`〔A｜原始文献:Euler, Institutiones calculi differentialis, 1755, Pars I, cap. I, p. 12（Opera omnia, Ser. 1, Vol. X, p. 96）〕`
**反例**：`〔A｜原始文献:Euler, 微分学原理〕` —— 无版次、无页码，等于没有定位。
**反例**：`〔A｜原始文献:Euler, Institutiones, 1755, p. 96〕` —— 页码取自重印本却标 1755 年版。

**工具**：部分。缺页码/版次可报 `warn`（启发式：出处里没有任何数字）。

### R4 编者导言为何不算原始

**判定**：导言、前言、编者按、题解、年表由后人撰写，即使与原始文献印在同一卷、同一册，也一律 `S`。
唯一例外：**作者本人**写的前言/自序 → `A`，且出处须写明"作者自序/作者前言"，以便与编者导言区分。
理由：导言是对原始文献的**解释**，它的可靠性依赖作者的学术判断，与原件是否可靠是两个问题。把导言标成 `A`，等于用一个解释去担保另一个解释。

**正例**：`〔S｜二手研究:Opera omnia, Ser. 1, Vol. X, 编者导言, p. vii〕`
**反例**：`〔A｜原始文献:同上, 编者导言, p. vii〕` —— 同一卷里，正文是 A、导言是 S，不能混。

**工具**：部分。出处含"导言/前言/编者按/introduction/editor's note"却标 `A`，报 `error`（除非同时含"作者自序/author's preface"）。

### R5 转引如何降级

**判定**：只见二手研究引用原始文献、未见原始文献原页 → **不得标 `A`**，标 `S` 并写明"转引自 <中转者> <定位>"。
- 中转者是**你实际读到的**那份文献。
- 若中转者本身是 `F`（科普、百科），整条降为 `F` 或 `U`。
- 转引链超过一层（A 被 B 引、你只见 C 引 B）→ 降为 `U`，并写明"未见 A，亦未见 B 原页"（见 T-5）。

**正例**：`〔S｜二手研究:转引自 Boyer 1949, p. 212；原文献 Cantor 1894, Bd. III, p. 89（未见原页）〕`
**反例**：`〔A｜原始文献:Cantor 1894, Bd. III, p. 89〕` —— 实际只从 Boyer 转述得知，却标成自己读过原件。
**反例**：`〔S｜二手研究:转引自某文献〕` —— 中转者不具名，无法核查。

**工具**：自动（语法层）。出处含"转引"但等级为 `A`、或"转引自"之后没有具名对象 → `error`。

### R6 二手研究互相矛盾如何处理

**判定**：
1. **并列**：两说都要写出，不得只引一边而假装另一边不存在。
2. **给理由**：说明取舍依据——更接近原始文献、更晚出且正面回应了前者、方法更可复核，三者至少给一条。
3. **裁不了就说不裁**：写"学界未定"，同时保留两条 `S`，并用一条 `U` 记录未裁断的原因与下一步核查路径。
4. 禁止用"学界公认"代替证据——"公认"本身是一个需要证据的断言。

**正例**：
```
柯西是否已掌握 ε 式论证，Grabiner（1981, pp. 45–52）持肯定，Katz & Katz（2012, §4）持部分否定。本文取前者，理由是 Grabiner 逐条比对了 1821/1823 两份讲义的手稿异文。
〔S｜二手研究:Grabiner 1981, pp. 45–52〕〔S｜二手研究:Katz & Katz 2012, §4（相反解读）〕
```
**反例**：只标一条 `S` 并写"这一点学界已有共识"，不写另一说。

**工具**：不可。工具无法判断两条二手文献是否矛盾，只能检查同一文献键是否被标了不同等级（R12）。

### R7 教科书与科普如何归类

**判定**：教科书正文、教材"历史注记"边栏、科普书、百科条目、公开讲座、博客、视频，一律 `F`。
`F` 只能作线索：用它支撑论断时，必须同时给出它指向的 `A` 或 `S`；给不出就转成 `U`。
注意一个反直觉的点：**数学上权威的教材，在史学上仍是 F**。教材的"历史注记"通常转述二手研究且不给出处，它的一致性不构成证据。

**正例**：`〔F｜流行说法:某高数教材「历史注记」边栏：柯西消灭了无穷小〕〔S｜二手研究:Grabiner 1981, ch. 2（结论相反）〕`
**反例**：`〔S｜二手研究:维基百科「Non-standard analysis」条目〕` —— 百科是 `F`，标 `S` 属于抬级。
**反例**：`〔A｜原始文献:某微积分教材, p. 233〕`

**工具**：自动（词表层）。出处命中百科/教材/科普词表却标 `A` 或 `S` → `error`。

### R8 "无法核实"在什么情况下允许出现

**判定**：`U` 只允许三种情形——
(a) 有具体线索（书目、馆藏号、期刊卷期）但未取得原件；
(b) 原件可得但关键页缺失、污损、无法释读；
(c) 只有口传、后人回忆、或来源不明的转述。

(c) 与 `F` 的界线：**读过那份流行文本、能指出它是哪一类**（教材"历史注记"边栏、百科条目、科普书、讲座），才归 `F`；只是"不知道谁写的"、连"可能是哪一类流行文本"都指不出，归 `U`，不归 `F`。`F` 的前提是确有一份可指的流行文本；`U` 的前提是没有可指的载体。

`U` 必须写**原因**和**下一步去哪查**。禁止两种滥用：
- 用 `U` 逃避判断：整段断言全部标 `U`，说明该段还不该发表；
- `U` 无原因或原因空转（"待查""不详""暂无"）——这等于没有标注。

**正例**：`〔U｜未核实:仅见 19 世纪书目著录，未见 1684 年原刊影像；待查 Acta Eruditorum 1684 年卷（Erlangen 大学数字化本）〕`
**反例**：`〔U｜未核实:待查〕`
**反例**：`〔U｜未核实:〕`

**工具**：自动。`U` 的出处为空，或只含"待查/不详/未知/TODO/n/a" → `error`。

### R9 批注与边栏材料如何处理

**判定**：分三种，不可混：
1. **作者自注**（同版印刷的脚注、边注、作者自序）→ `A`，出处注明"作者自注"。
2. **后人批注**（藏书家题跋、铅笔边注、夹页）→ 必须写明批注者与载体（哪一册、哪个馆藏、馆藏号）。批注者可考且属同时代重要人物时按 `A` 处理；批注者佚名 → `U`（见 T-6）。
3. **现代编者夹注** → `S`（同 R4）。

另有一类**不是史料**的边栏：本文作者自己的解释性旁栏。它不挂证据等级，但必须在文中显式声明"不承担推理"，否则读者会把它当史实。

**正例**：`〔A｜原始文献:Euler E212, §..., 作者自注〕`
**正例**：`〔U｜未核实:某藏本边注，批注者佚名，仅见馆藏目录著录（Cambridge, Trinity College, N.4.2）〕`
**反例**：`〔A｜原始文献:某藏书家铅笔边注〕` —— 无批注者、无馆藏、无载体。

**工具**：部分。出处含"边注/批注/题跋/marginalia"却无馆藏或编号时可报 `warn`。

### R10 网络档案的引用格式

**判定**：引用数字化档案必须四件套——**站点名 + 稳定标识 + 页码/图版号 + 访问日期**。
禁止只给站点首页、搜索结果页或短链——它们会失效、也会让不同版本的影像混为一谈。
机器可解析程度排序（高→低）：`DOI` > `ARK` > `handle` > 站点内永久链接 > 普通 URL。

**正例**：`〔A｜原始文献:L'Hôpital, Analyse des infiniment petits, 1696, p. 3；ARK:ark:/12148/bpt6k205444w（Gallica，访问 2026-11-13）〕`
**反例**：`〔A｜原始文献:https://gallica.bnf.fr/ 上搜到的 1696 年版〕` —— 无稳定标识、无页码、无访问日期。
**反例**：`〔A｜原始文献:某短链 https://t.cn/xxxx〕`

**工具**：部分。URL 无 scheme/host 报 `error`；有 URL 但无访问日期报 `warn`；`--online` 时可探测存活（见工具文档）。

### R11 同一文献多个可获取入口如何取舍

**判定**：出处只写**一个主入口**，按 R10 的优先级选；其余入口记在文献台账（Zotero 条目等），不进正文标记。
理由有两条：一是多入口并列会让"同一文献不同等级"的检查失效（同一个键挂了三行不同信息）；二是读者需要知道**你实际看的是哪一份**，而不是有哪些份存在。

**正例**：`〔A｜原始文献:Newton, Principia, 1687, Lib. I, Lem. II；URL:https://www.newtonproject.ox.ac.uk/view/texts/normalized/NATP00056（访问 2026-11-13）〕`
**反例**：`〔A｜原始文献:Newton, Principia, 1687（archive.org / Gallica / Newton Project 均可查）〕`

**工具**：部分。出处中出现多个 URL（≥2）报 `warn`。

### R12 引用键的稳定性

**判定**：同一文献在全文必须使用**同一个引用键**。建议格式 `<作者姓> <年>`（`Grabiner 1981`）或 `<全集编号>`（`Euler E212`）。页码可以随句变化，键不能变。
这是工具能做"同一文献被标成不同等级"检查的前提：工具不认识"Grabiner 1981"和"Judith Grabiner, *The Origins of Cauchy's Rigorous Calculus*"是同一条文献，除非作者自己保持键稳定。

**正例**：全文两处都用 `Grabiner 1981`。
**反例**：一处 `Grabiner 1981`，一处 `Judith V. Grabiner, The Origins of Cauchy's Rigorous Calculus, MIT Press, 1981`，一处 `Grabiner, Origins`。

**工具**：部分。工具按"去掉页码与年份后的出处前缀"归一化后比对；键写法差异过大时无法识别，会漏报——这是本规范已知的局限。

### R13 标记挂载位置

**判定**：标记挂在**被支持的句子或段落末尾**，紧贴句号（句号前或后一格均可）。
- 一段里若有多个不同来源的断言，**拆句分别挂**。
- 整段同源时允许段末挂一个标记。
- 表格单元格内的标记挂在单元格文本末尾。
- 标题、代码块、纯过渡句不挂标记。

**正例**：
```
莱布尼茨 1684 年的论文里，$dx$ 未被定义为无穷小。〔S｜二手研究:Cantor 1894, Bd. III, p. 89〕
```
**反例**：一段里讲了欧拉、柯西、魏尔斯特拉斯三件事，末尾只挂一个 `〔S｜二手研究:Grabiner 1981〕`。

**工具**：部分。工具能检查"段落是否完全没有标记"，不能检查"标记是否挂错了句子"。

### 规则的效力分类与关键度

R1–R13 不是同一类东西。把它们平铺并列，会让读者以为每条都在决定等级。分三类：

| 类别 | 做什么 | 条款 |
|---|---|---|
| **判定类** | 读取 §1.5 的六个维度，对可能的等级集合作出限制 | R1、R2、R3、R4、R5、R7、R8、R9 |
| **程序类** | 规定冲突发生时怎么写，自身不产生等级 | R6 |
| **格式类** | 只约束出处的写法与标记的位置，从不改变等级 | R10、R11、R12、R13 |

格式类条款删掉，任何一行的等级都不变。这不等于它们可删：它们管的是"能不能被机器核对"，与"判成哪一级"是两个问题——R13 删掉，工具就无法定位标记；R12 删掉，`MULTI_GRADE` 检查就失效。**格式类的关键度应记为"不适用"，不是 0。**

**关键度**的定义：在 §1.5 压缩后的情境集上，删掉某一条后判定结果发生改变的行数。"判定改变"包含两种：状态改变（唯一 / 不定 / 冲突 互换），或同为唯一但唯一等级不同。

关键度为 0 有两种成因，写法上必须分开，不得合并成一句"无贡献"：

1. **空转（说明性）**：该条对任何一行都返回全集，从未参与判定。这类条款只能作说明，**不得与判定条款并列**；规范中须明确标注"仅作说明性条款、不参与判定"。
2. **被吸收**：该条对若干行给出了限制，但这些限制已被其他条款共同蕴含，删掉不改变结果。这类**仍是判定条款**，只是当前规则集下冗余；标注应写"被 R<编号> 吸收"，并保留在原位——规则集一变，它可能重新变成关键条款。

因此每条判定类条款都要同时报两个数：**参与行数**（返回非全集的行数）与**关键度**。只有"关键度 0 且参与行数 0"才是空转。

现行 v0.1 没有空转条款：逐条测过的六项判定核关键度均大于 0；R4 未单独测（其情形由 R2/R5 的点校本与校记分支覆盖），不构成空转。v1 基线里 R2、R3、R8 出现"关键度 0、参与行数大于 0"，那属于被吸收，按第 2 条处理，不得删除。

> 逐条数值、两套口径（v1 基线 160 / 86；v0.1 编码 168 / 90）、以及 Alloy 6.2.0 第二实现的交叉验证方案，见 `docs/spec-audit.md`。数字随规则集版本变动，不属于本规范的稳定正文；Alloy 是维护者工具，不是使用本规范的前提。

|---|---|

## 4. 冲突处理

### 4.1 同一论断有两种等级并存

写法：**先低后高，且说明为什么高等级没能覆盖全部内容**。

```
〔S｜二手研究:Grabiner 1981, p. 47〕〔A｜原始文献:Cauchy 1823, p. 12（原文只给出这一句，未给证明）〕
```

判据：
- 若 `A` 能完整支撑该论断 → 只留 `A`，删掉 `S`。`S` 在此只起"解释"作用时，应移到正文叙述里而不是标记里。
- 若 `A` 只能支撑一半（例如原文有断言、无证明）→ 并存，并在正文一句话说明哪半由谁支撑。
- `A` 与 `F` 并存通常意味着**要纠正误说**：`F` 在前（记录误说）、`A` 在后（给出纠正）。这时正文必须显式写出"误说 / 纠正"结构，不能只堆标记。
- `U` 与任何等级并存是合法的：`U` 记录"还有一块没核"。

### 4.2 同一文献在两处被标成不同等级

这是**错误**，不是"两种视角"。可能的正当原因只有两个：两处引的是同一著作的不同部分（正文 vs 编者导言），或一处是转引、一处是原页。两种情形都必须把差异写进出处（"编者导言""转引自"），让工具能区分；否则工具会报 `MULTI_GRADE`，须改。

## 5. 机器能验 / 不能验

| 能做 | 做不到 |
|---|---|
| 标记语法是否合法（括号、竖线、冒号、等级字母） | 这条文献是不是真的原始文献 |
| 出处里的 DOI / ISBN / URL / 档案 ID 格式是否可解析 | 这个出处是否真实存在（离线模式） |
| 等级与来源类型是否自洽（百科标 A、导言标 A、转引标 A） | 作者对该文献的等级判断是否正确 |
| `U` 是否写了原因 | 原因是否成立 |
| 同一引用键是否被标了不同等级 | 两条不同写法的出处是否是同一文献 |
| 哪些段落完全没有标记 | 标记挂的那句话是否真的由该文献支持 |
| （`--online`）链接是否存活、DOI 是否可解析 | 链接内容是否与正文论断相符 |

一句话：**工具验证引文可解析性与等级自洽，不验证历史意图与等级判定本身。**

### 5.1 一致性审计的报数口径

规则集会被反复修改，"改完冲突是多了还是少了"必须用固定口径回答，否则数字不可比。三条：

1. **只报冲突率，不报冲突条数。** 分母随 §1.5 的压缩而变，条数没有跨版本可比性。
2. **报去重后的口径，宽窄两个都给。** 宽口径（维度有指称即算活）是对外口径；窄口径（只算被规则真正读取的维度）是保守下界。同一情境的不同写法（E2 / E5 / E6 造成的重复）只算一次。
3. **冲突与不定必须同时报。** 冲突为 0 而不定不为 0，说明规则集给不出等级，这不是"一致"。

基线（§1.5 压缩的算术后果）：

| 阶段 | 宽口径 | 窄口径 |
|---|---|---|
| 六维笛卡尔积 | 1620 | 1620 |
| 经 E1 / E3 / E4 剔除 | 376 | 376 |
| 经 E2 / E5 / E6 归并 | 168 | 90 |

这是 v0.1 编码（15 类载体，含未分层的"点校本"）的结果：唯一 118 / 64，不定 16 / 8（9.5% / 8.9%），冲突 34 / 18（20.2% / 20.0%）。这条基线是**问题清单，不是合格线**——它的用途是判断"改一条规则是否真的减少了冲突"。

2026-11-16 起，审计提出的 v1 修订（S-1–S-6）被采纳为基线。口径如下，引用时必须一并给出：

- **载体 14 类**：按 §1.5 的要求，"点校本"必须写明正文或校记，未分层的那一类不再进入情境空间。
- **分母**：v1 的笛卡尔积是 1512，经 E1 / E3 / E4 剔剩 356，按 E2 / E5 / E6 去重后为 **160（宽）/ 86（窄）**；相对 1512 的压缩比约 9.5×（宽）与 17.6×（窄）。
- **结果**：160 与 86 全部唯一，冲突 0 / 0，不定 0 / 0（0% / 0%）。
- **不得只写"0 冲突"**：分母、宽窄口径、两步剔除缺任何一项，"0" 就不成立——换一个空间，它就不是 0。

这组数字由 `tools/audit/`（`python -m tools.audit`，见内部文档 §5）复现，`tools/tests/test_audit.py` 锁定基线值。

## 6. 本规范中我自己不确定的条款

以下条款标为**待议**，理由是我没有足够依据把它定成硬规则。它们不是"以后再说"，而是"现在就是这么用的，但我知道它可被推翻"。

**T-1 学生课堂笔记算 `A` 还是 `S`**
倾向 `S`：笔记经过记录者转手，且常有听误。但若笔记经作者本人校订、或作者授课时以笔记为讲义底本，则应算 `A`。我无法给出可操作的判据，故留在待议。

**T-2 作者晚年回忆算 `A` 还是 `S`**
这是本规范最没有把握的一条。回忆录、晚年书信、事后追述由作者本人写成，按 R1 的字面条件是 `A`；但记忆重构、事后合理化、为自己辩护的成分使其证据力接近 `S`。
本规范暂定：**标 `A` 并在出处写"事后追述"**，由读者自行折价。但我承认另一种做法（一律降 `S`）同样有理。第一期正文里对莱布尼茨"一道光突然照进来"的回忆就按 `S` 处理，与本条的暂定相反——这个不一致是真实存在的，不掩饰。

**T-3 影印本算不算 `A`**
影印本可以替代原件用于**文字核对**，但不能用于纸张、水印、装帧、递藏等版本学判断。本规范允许影印本标 `A`（限定用途），但如果你的论断涉及"这一版是不是初版"，影印本不足。

**T-4 只见重印本、未见原始卷期怎么办**
例如某 19 世纪论文只见 1960 年代重印本。按 R3 仍可标 `A`（内容同一），但出处必须写明"据 19xx 年重印本，原刊卷期待查"，否则读者会以为你核过原刊。这条与 R10 的"主入口"原则有张力，我倾向前者（诚实标注获取路径）。

**T-5 转引链的降级阈值**
本规范定"一层降 `S`、两层降 `U`"。两层就降 `U` 可能过严：有些经典文献的转引链是学界常态，两层转引仍相当可靠。但我没有数据支持一个更细的阈值，故从保守端取值。

**T-6 佚名批注的等级**
见 R9。定 `U` 是保守选择；若批注内容本身构成独立史料（例如记录了某次谈话），或许该按内容定级而非按作者定级。此事无定论。

**T-7 本规范本身**
`A/S/U/F` 四分法不是史学界通用标准（史学界常用"一手/二手"二分，或按史料批判的"真伪—可靠—相关"三维）。四分法是为**机器可检查**而设计的折中：等级太少则区分不出"转引"与"未核实"，太多则作者记不住、工具判不了。如果将来证明四分不够用，应改规范而不是给工具打补丁。

## 7. 最小使用流程

1. 写作时随手挂标记，宁可标 `U` 也不要空着。
2. 每节写完跑一次 `mathlint check 章节.md`，先清 `error`（语法与自洽），再看 `warn`（缺标记、`U` 写得太糊）。
3. 定稿前跑 `mathlint check . --strict`，`warn` 也当失败处理。
4. 需要核查链接时跑 `--online`；注意它区分"链接失效"（4xx/5xx）与"网络不可达"（DNS/超时），后者不构成"文献有问题"的证据。
