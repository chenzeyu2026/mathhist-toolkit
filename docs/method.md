# 一份证据标记规范的使用记录

> 这不是论文，也不是方法创新。它是一份工具说明加一次真实使用的流水账：我们给写数学史文章的人做了一套标记规范和一个检查器，然后在四万一千字的正文上跑了一遍，记下它抓到了什么、漏了什么。

## 1. 为什么需要分级

写数学思想演化的人大概都遇到过同一种追问："你怎么知道牛顿是这么想的？"回答通常有三种：我读过原页；我看的是研究著作；我记不清了，但大家都这么说。这三种回答的证据力差着数量级，可在文章里它们长得一模一样——都是陈述句。

读者无法分辨，作者自己过几个月也未必分得清。更麻烦的是第三类会自我繁殖：科普转述被教材转述，教材被文章引用，最后文章成了新的"大家都这么说"。

所以这里做的第一件事不是写工具，而是规定四类标记：

- `〔A｜原始文献:出处〕`——作者本人写的、同时代的、能定位到版次页码的东西；
- `〔S｜二手研究:出处〕`——同行评议的专著与论文、学术版导言；
- `〔U｜未核实:原因〕`——有线索引号但没见到原件；
- `〔F｜流行说法:出处〕`——教材、科普、百科、讲座。

四级不是史学界的通用分法。它是个折中：等级太少，分不出"转引"和"未核实"；太多，作者记不住，工具也判不了。这个取舍本身写进了规范 §6（标为待议），没有装作是定论。

## 2. 规范怎么用

写作时随手挂，不要留白；留白的地方后来一定会被忘掉。

判断顺序只有三步：

1. **这是谁写的？** 作者本人 → A 的候选；后人 → S 的候选；不知道 → U 的候选。只有当你读过那份流行文本、能指出它是哪一类（教材边栏、百科条目、科普书、讲座）时，才按 `F` 处理；连"可能是哪一类"都指不出，就是 `U`。
2. **我实际看到的是哪一份？** 原件、影印、重印、译本、别人转述——这一步决定要不要降级。只见二手研究引原页，必须写"转引自 <中转者>"并降到 S（规范 R5）。
3. **能不能定位？** 版次 + 页码，或者卷期 + 页码，或者馆藏号 + 页码。定位不了就不是 A。

两个最常见的误用：

- **把教材当权威**。数学上权威的教材，在史学上仍是 F。教材的"历史注记"通常转述二手研究且不给页码，它前后一致不构成证据。
- **用 U 逃避判断**。整段全是 U，说明这段还不该发。U 的合法用途只有三种：有线索没取到、原件损坏、只有口传或来源不明的转述（规范 R8）。

定稿前跑一次 `mathlint check . --strict`，让 warn 也拦住提交。

## 3. 工具能验什么

`mathlint` 做六件事，都是机械可判的：

1. 标记语法：括号是不是全角 `〔〕`、有没有 `｜`、等级字母是不是 A/S/U/F、出处是否为空；
2. 论断是否完全没有标记：按段落与列表项切分，长于阈值且有句末标点的单元算论断；
3. 出处里的标识符能否解析：DOI 前缀与后缀、ISBN 校验位、URL 的 scheme 与 host、ARK 的 `ark:/` 前缀；
4. 等级与来源类型是否自洽：百科/教材标成 A 或 S、编者导言标成 A、转引标成 A，都报 error；
5. `〔U〕` 是否写了原因，以及原因是不是"待查"这类空话；
6. 同一引用键是否在两处被标成不同等级。

`--online` 另外探测链接存活与 DOI 解析，并且**区分两种失败**：4xx/5xx 是"链接失效"（error），DNS 失败或超时是"网络不可达"（info）。后者不构成"这条文献有问题"的证据——把网络故障当成文献缺陷，是这类工具最容易犯的错。

## 4. 工具验不了什么

必须说清楚：**工具验证引文可解析性与等级自洽，不能验证历史意图与等级判定本身。**

具体地说，它做不到：

- 判断一条文献是不是真的原始文献。它只认词表：出现"维基""教科书"就报不自洽，但一篇标成 A 的 1684 年期刊论文，它无法确认那真是 1684 年的卷期。
- 判断作者的等级判断对不对。把 Boyer 1949 标成 A，它会报错（因为 Boyer 不是同时代）；但把 Boyer 1949 标成 S 之后，Boyer 的结论是否可靠，它一无所知。
- 离线判断出处是否真实存在。它只检查格式。
- 判断两条写法不同的出处是不是同一文献。这依赖作者保持引用键稳定（规范 R12），键写得花，它就会漏报。
- 判断标记挂的那句话是否真由该文献支持。它能查"这一段有没有标记"，查不了"标记挂错了句子"。

这几条不是待办事项，是这类工具的边界。任何声称能自动判定史料等级的检查器，都在替作者做它做不了的判断。

## 5. 一次真实使用

对象是一篇四万一千字的正文（微积分起源，第一期）。基线结果：

- 96 个 error，全部来自同一种旧式简写：`【原】`、`【研】`、`【原/研】`、`【传】`。
- 242 个 warn：达到判定阈值的论断段落，一个标记也没有。

旧式简写为什么算 error？因为它把"等级"和"出处"压成了一个两字标签。`【原】` 告诉你作者认为这是一手材料，但没告诉你哪一版哪一页，于是既无法核，也无法在事后比较。这正是"一手文献散在多个库"那个痛点的技术形态。

修补只做三件事：把简写换成规范标记、把段末括注里的书目信息折进出处、给没有出处的标记写 `待补出处`。不代填任何文献，不改任何论证句。

结果：error 96 → 0；warn 242 → 227。数字上 warn 只降了 15，因为 93 条新标记里有 29 条出处是空的、17 条只有书名没有版次页码、3 条把教材例题标成了 S。这些都被逐条报了出来——**它们是真实存在的问题，不是工具的噪声**。

剩下 178 个 warn 是正文从来没给出来源的段落。补标记等于补文献，那已经超出"只改格式"的范围，所以留着。

## 6. 已知问题

- **段落切分是启发式的**：代码块、表格、标题会跳过，但引用块里的"误说／纠正"会被算作论断；短于阈值的断言不检查。
- **词表会误伤**：出处里出现"教材"就提示降级，但"某教材第 3 页记载了 1687 年原刊的影印"这种情况会被误报。
- **引用键靠作者自觉**：同上一条，工具没有能力做文献消歧。
- **不判"同时代"**：R1 的核心条件（同时代）无法机械判定，只能靠作者。

## 7. 适合谁

适合：写长文、要面对"你怎么知道"这类追问、愿意在写作时就花几秒钟挂标记的人。

不适合：写科普短文、不需要给出处的场景；也不适合想用工具替代判断的人——这套东西的前提是作者先做判断，工具只负责让判断留下痕迹。
