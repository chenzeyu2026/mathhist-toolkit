# `MISSING_TAG` 阈值敏感性（v0.1.0 记录）

> 目的：给"论断缺标记"这条检查的启发式阈值做一次可复现的敏感性观察。
> 结论先说：**当前取值（段落 40 字 / 列表项 24 字）落在连续变化的中段，不是自然分界点；本次数据不支持改用其他值，也不足以否定当前值。**

## 1. 这条检查怎么判

`MISSING_TAG` 只对满足以下条件的"单元"生效（单元 = 段落或列表项）：

1. 单元文本不以 `不承担推理` 开头或包含它，也不以 `旁栏` 开头；
2. 至少含一个句末标点 `。！？`；
3. 中日韩汉字与拉丁字母合计 ≥ 阈值。

阈值目前写死在 [`tools/mathlint/checks.py`](../tools/mathlint/checks.py) 的 `_looks_like_claim()`：段落 40，列表项 24（约为段落的 0.6 倍）。

## 2. 怎么跑

在同一份语料 `corpus/01-微积分起源.md`（41 070 字符）与它的修补稿 `corpus/01-微积分起源.patched.md`（43 669 字符）上，把段落阈值从 20 扫到 80，列表项阈值固定为段落的 0.6 倍，其余判定条件不变。脚本见 §5。

"判定为论断"= 通过上述三条的单元数；"无标记"= 其中所在行没有标签的单元数（即 `MISSING_TAG` 条数）。

## 3. 结果

| 段落阈值 | 列表项阈值 | 原稿：判定为论断 | 原稿：无标记 | 修补稿：判定为论断 | 修补稿：无标记 |
|---:|---:|---:|---:|---:|---:|
| 20 | 12 | 277 | 277 | 277 | 211 |
| 25 | 15 | 272 | 272 | 272 | 206 |
| 30 | 18 | 265 | 265 | 265 | 199 |
| 35 | 21 | 256 | 256 | 256 | 190 |
| **40** | **24** | **242** | **242** | **244** | **178** |
| 45 | 27 | 228 | 228 | 233 | 167 |
| 50 | 30 | 209 | 209 | 214 | 149 |
| 60 | 36 | 179 | 179 | 185 | 121 |
| 80 | 48 | 123 | 123 | 131 | 72 |

原稿没有标签，所以"判定为论断"与"无标记"恒等，两条列相同是预期结果。修补稿在 40 阈值下的 178 条，与 `mathlint` 实际报出的 `MISSING_TAG 178` 一致——说明这套统计口径与工具实现是同一个。

## 4. 怎么读这张表

- **没有平台。** 从 20 到 80 是平滑下降，没有哪一段出现"再怎么调，命中数都不变"的稳定区间。这说明字数与"是不是论断"在这份语料里没有天然断层，阈值只能是一个约定。
- **局部斜率。** 40 附近每上调 5 字，少判 8–14 段（约 3%–6%）；每下调 5 字，多判 5–9 段。改动 5 字就会改变十几条报告，使用者能感知到。
- **40 的位置。** 它把 277 段压到 242 段，丢掉约 13%；若取 30，几乎全收（265），会放进更多过渡句；若取 50，会漏掉 33 段较短的论断。**40 是"宁可多报"与"别太吵"之间的一个中间值，不是最优点。**
- **修补稿的差值略高。** 同一阈值下修补稿判定的论断数比原稿多 2–8 段，因为插入标签改变了单元文本长度。这类边界抖动无法消除，只能接受。

## 5. 复现

```python
# 在工作目录下运行；只需把 ROOT 指向仓库
import re, sys
sys.path.insert(0, r"<repo>\tools")
from mathlint import checks

def count(text, para_th):
    item_th = round(para_th * 0.6)
    tags, _ = checks.scan(checks.mask_non_prose(text))
    tagged = {t.line for t in tags}
    claims = untagged = 0
    for start, end, unit, is_item in checks.iter_units(text):
        if not unit or "不承担推理" in unit or unit.startswith("旁栏"):
            continue
        if not re.search(r"[。！？]", unit):
            continue
        if checks._cjk_letters(unit) < (item_th if is_item else para_th):
            continue
        claims += 1
        if not any(line in tagged for line in range(start, end + 1)):
            untagged += 1
    return claims, untagged

text = open(r"<repo>\corpus\01-微积分起源.md", encoding="utf-8").read()
for th in (20, 30, 40, 50, 60, 80):
    print(th, count(text, th))
```

## 6. 这次没有做的事

- **没有第二份语料。** 单一作者、单一主题、单一文体（面向大一学生的连续叙述）。换一种文体（书评、术语考据、年表）斜率可能完全不同。
- **没有人工标注。** 没有"这 242 段里，人认为是论断的有几段"这个金标准，因此无法计算准确率与召回率，只能看数量变化。
- **没有据此改默认值。** 在拿到第二份语料与人工标注之前，40/24 保持不动。

要真正校准，需要的是一次小规模标注：随机抽 100 个单元，两人独立标"是论断/不是论断"，再算不同阈值下的 F1。这件事列在 [`RELEASE-CHECKLIST.md`](../RELEASE-CHECKLIST.md) 里，公开发布前完成。
