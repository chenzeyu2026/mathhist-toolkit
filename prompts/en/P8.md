# P8 — Cross-checking two contemporary sources

> Verbatim (source: `附录_数学思想史工具与指令集.md` §6). English rendering of the Chinese prompt.
> Use when: two sources from the same period answer one question differently.
> Grade note: the text uses the four-level A/S/U/F scheme; see the [spec](../../spec/evidence-tags.en.md).

```
Below are two passages from contemporary sources on the same problem. Cross-check them; do not adjudicate.

Source one: {{author, year, page}} + passage
Source two: {{author, year, page}} + passage

Output:
1. What does each take "the problem" to be? If it is the same problem, give one shared formulation.
2. Element-by-element table: object / method / criterion of acceptability / conclusion | source one | source two | is this a real conflict?
3. If the conflict is apparent, distinguish three cases — (a) same words, different referents; (b) same referent, different standards; (c) a real disagreement — and give the criterion.
4. If you cannot adjudicate, say "cannot be adjudicated at present" and list the material that would settle it.

Forbidden: averaging the two conclusions into a "more complete" statement.
```
