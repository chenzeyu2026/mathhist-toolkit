# P7 — Writing a "misstatement / correction" pair

> Verbatim (source: `附录_数学思想史工具与指令集.md` §6). English rendering of the Chinese prompt.
> Use when: correcting a popular claim; first pin down its exact form.
> Grade note: the text uses the four-level A/S/U/F scheme; see the [spec](../../spec/evidence-tags.en.md).

```
I want to correct a popular claim: {{one-line misstatement}}

Produce four parts, each tagged with a grade:

1. The **exact form** of the misstatement: in which kinds of text does it appear most (textbook sidebar, popular book, encyclopedia, lecture)? How is it usually phrased? Give one representative locus.
2. Why the misstatement is attractive: which narrative need does it serve? (One sentence; no essay.)
3. The correction: what do the primary sources actually say? Give a checkable page and the passage (original language + gloss).
4. What the correction costs: what phenomenon did the misstatement explain, and what explains it now?

Requirement: part 3 must rest on a primary source. If only secondary work is available, write "quoted at second hand from X" and say why the original page was unavailable.
Do not use "history is more complicated than that" as a correction.
```
