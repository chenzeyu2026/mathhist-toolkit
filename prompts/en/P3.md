# P3 — Ledger of unverified claims

> Verbatim (source: `附录_数学思想史工具与指令集.md` §6). English rendering of the Chinese prompt.
> Use when: converting "I remember something like this" into items that can be closed one by one.
> Grade note: the text uses the four-level A/S/U/F scheme; see the [spec](../../spec/evidence-tags.en.md).

```
Turn the following statements into a ledger of unverified claims that I can close one by one.

Statements:
"""
{{paste several statements}}
"""

For each item output: id | statement | lead I currently have | what material would verify it (specific document type / holding / database) | suggested search path (a concrete query or database name) | risk if it is wrong

Requirements:
- Do not "reasonably infer" a conclusion for me. Only give the verification path.
- The search path must be specific enough to run, e.g. "zbMATH: MSC 01A50 + keyword infinitesimal", not "consult the literature".
- Sort the list by how easy each item is to verify.
```
