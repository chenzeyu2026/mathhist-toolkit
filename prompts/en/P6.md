# P6 — Cross-linguistic alignment of a term

> Verbatim (source: `附录_数学思想史工具与指令集.md` §6). English rendering of the Chinese prompt.
> Use when: one concept carries different names across languages or periods.
> Grade note: the text uses the four-level A/S/U/F scheme; see the [spec](../../spec/evidence-tags.en.md).

```
Build a cross-linguistic alignment table for the concept {{concept}}.

Columns: language / period | original term | literal meaning | earliest attestable text (author, year, page) | what it meant then | how it differs from today's {{concept}} | grade (A/S/U/F)

Requirements:
- "Earliest attestable" needs a page. If you cannot give one, mark U and give the search path.
- If a language has no equivalent term, write "no equivalent term" and say which broader word covered it at the time.
- "What it meant then" must rest on the text, not on later interpretation.
- End with three translation choices most likely to mislead, one example each.
```
