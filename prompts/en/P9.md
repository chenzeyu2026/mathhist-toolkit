# P9 — Closing a section: compress conclusions back to evidence

> Verbatim (source: `附录_数学思想史工具与指令集.md` §6). English rendering of the Chinese prompt.
> Use when: a section is done and about to be finalised.
> Grade note: the text uses the four-level A/S/U/F scheme; see the [spec](../../spec/evidence-tags.en.md).

```
This is the conclusion paragraph of my section. Check each conclusion: which are directly supported by the evidence, and which add a step of my own between evidence and conclusion?

Paragraph:
"""
{{conclusion paragraph}}
"""

For each conclusion output:
- the minimal evidence set that supports it (down to page numbers)
- the extra step added in the inference (e.g. from "he did not write it" to "he did not know it")
- how the conclusion should be phrased to remain true without that step
- the highest grade the conclusion can currently carry

End with a verdict of "publishable / needs downgrading / needs deleting" for each, with reasons.
```
