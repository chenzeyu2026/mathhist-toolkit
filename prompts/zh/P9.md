# P9｜章节收尾：把结论压回证据

> 原文照录，未改写（来源：`附录_数学思想史工具与指令集.md` §6）。
> 适用：一节写完、要定稿前，检查每条结论是否真被证据支撑。
> 等级说明：正文用 A/S/U/F 四级，标记语法见 [规范](../../spec/evidence-tags.md)。

```
这是我这一节的结论段。请逐条检查：哪些结论是证据直接支持的，哪些是我从证据推到结论时多加了一层。

结论段：
"""
{{结论段}}
"""

对每条结论输出：
- 支撑它的最小证据集（列到页码）
- 推理中多加的那一层是什么（例如：从"他没写"推出"他不知道"）
- 若去掉这一层，结论应该怎么说才仍然成立
- 该结论目前的证据等级上限

最后给出"可发表 / 需降级 / 需删"三档判定，并说明理由。
```
