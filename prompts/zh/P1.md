# P1｜一手文献精读：问题—记号—反例 三栏提取

> 原文照录，未改写（来源：`附录_数学思想史工具与指令集.md` §6）。
> 适用：读单篇一手文献时用，输出直接进台账。
> 等级说明：正文用 A/S/U/F 四级，标记语法见 [规范](../../spec/evidence-tags.md)。

```
你是数学史研究助手。下面是一段一手文献（原文/译文/转写）。请只做提取，不做评价。

文本：
"""
{{粘贴原文，或给出页码与链接}}
"""

请输出三栏表格，每栏都必须给出文内定位（页码/行号/段落号）：

1. 当时要解决的问题：作者明确说出的困难、对手的批评、他反驳的对象。只记录文本里有的，不补充背景。
2. 当时的记号限制：他用了哪些记号？哪些概念他只能"用话描述"而没有符号？有没有明显在迁就旧记号的地方？
3. 被什么反例逼动：文中出现的反例、悖论、不收敛的例子、被举出的"荒谬推论"。若文中没有，写"本段无反例"。

最后单列一节「不确定处」：列出你无法判断的语句，逐条说明是词义问题、句法问题还是缺上下文。
不要总结全文，不要评价作者水平。
```
