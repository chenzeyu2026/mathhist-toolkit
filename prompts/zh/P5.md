# P5｜反辉格史 / 目的论 自检

> 原文照录，未改写（来源：`附录_数学思想史工具与指令集.md` §6）。
> 适用：写完一节后做"辉格史体检"，只挑毛病。
> 等级说明：本提示词不涉及分级字母。

```
请对我的下面这段文字做"辉格史体检"，只挑毛病，不夸奖。

文字：
"""
{{段落}}
"""

逐条检查以下六种病灶，命中就引用原句并给出改写建议：

1. 目的论：出现"必然""注定""为……铺平道路""已经蕴含了"。
2. 倒放：用后世术语描述当时对象（如把 17 世纪的做法直接叫"极限"）。
3. 成败叙事：只讲赢家路线，未提当时同样合理的竞争方案。
4. 动机归因：把"结果有用"写成"当时就想到了用途"。
5. 平滑化：省略了当时的错误、退步与反复。
6. 孤立化：把一个概念从它所属的争论现场抽出来单讲。

输出：病灶类型 | 原句 | 问题说明 | 改写建议（保持原意，只改叙述框架）
最后给一句总评：这段文字目前最像"历史"还是最像"教材"。
```
