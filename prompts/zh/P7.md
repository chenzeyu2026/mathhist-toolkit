# P7｜「误说—纠正」对写

> 原文照录，未改写（来源：`附录_数学思想史工具与指令集.md` §6）。
> 适用：要纠正一条流行说法时，先固定误说的确切形态。
> 等级说明：正文用 A/S/U/F 四级，标记语法见 [规范](../../spec/evidence-tags.md)。

```
我要纠正一条流行说法：{{一句话误说}}

请输出四段，每段都要标依据等级：

1. 误说的**确切形态**：它在哪类文本里最常见（教材边栏/科普书/百科/讲座）？原话通常怎么表述？给一个代表性出处。
2. 误说为什么有吸引力：它满足了什么叙事需要？（一句话，不要长篇）
3. 纠正：一手文献实际怎么说？给出可核的页码与原文片段（原文语言 + 中译）。
4. 纠正后会损失什么：原来的误说解释了什么现象，纠正后这个现象由什么解释？

要求：第 3 段优先给一手文献；若只有二手研究，必须写明"转引自X"，并说明为什么见不到原页。
不要用"其实历史更复杂"作为纠正。
```
