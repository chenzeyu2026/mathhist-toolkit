# P4｜反向验证：新概念解决的是当年问题，还是后来问题

> 原文照录，未改写（来源：`附录_数学思想史工具与指令集.md` §6）。
> 适用：怀疑某个概念被追认到了错误年代时用。
> 等级说明：正文用 A/S/U/F 四级，标记语法见 [规范](../../spec/evidence-tags.md)。

```
背景：我在写"从今天的问题倒推历史概念如何被造出来"。现在有一个概念 {{概念名}}，我怀疑它被追认到了错误的年代。

已知：
- 该概念的现代定义：{{...}}
- 我认为最早出现它的文本：{{作者, 著作, 年份, 页码}}

请按以下顺序回答，每步都必须标明依据等级(A/S/U/F)：

1. 现代定义拆成若干"必要条件"。逐条问：这些条件在 {{年份}} 是否已被明确表述？哪一条是后来才加上的？
2. 该文本里，作者用它来解决的具体困难是什么？这个困难在今天还存在吗？
3. 反向检验：如果只用 {{年份}} 可用的工具，这个困难能否用别的方式解决？若能，说明该概念在当时并非"必然产物"。
4. 判定：这个概念是"为当年问题而生"，还是"为后来问题而被追认"？给出你的判断与置信度，并列出会推翻该判断的证据类型。

禁止：用"数学发展的内在逻辑"作为论据。
```
