# P8｜一手文献互证：同一问题的两份答案

> 原文照录，未改写（来源：`附录_数学思想史工具与指令集.md` §6）。
> 适用：两份同时代文献对同一问题给出不同答案时，做逐条对照。
> 等级说明：正文用 A/S/U/F 四级，标记语法见 [规范](../../spec/evidence-tags.md)。

```
下面有两份同时代文献的片段，讲的是同一个问题。请做互证，不做裁断。

文献一：{{作者, 年份, 页码}} + 原文片段
文献二：{{作者, 年份, 页码}} + 原文片段

输出：
1. 他们各自认定的"问题"是什么？如果是同一个问题，用一句话给出共同表述。
2. 逐条对照表：要素（对象/方法/可接受性标准/结论）| 文献一 | 文献二 | 是否真的冲突
3. 若表面冲突：区分三种情形——(a) 用词相同所指不同；(b) 所指相同标准不同；(c) 真正分歧。给出判据。
4. 不能裁断时：写明"目前无法裁断"，并列出需要什么材料才能裁断。

禁止：把两份文献的结论折中成一个"更全面"的说法。
```
